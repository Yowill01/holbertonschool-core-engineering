# Python - Exception Handling

This project covers how Python handles runtime errors using
`try` / `except`, specific exception types, `else` and `finally`,
and explicitly raising exceptions.

## Tasks

### 0. Safe list printing
`safe_print_list.py` contains `safe_print_list(my_list=[], x=0)`,
which prints `x` elements of a list on one line and returns the
number of elements actually printed. It uses `try` / `except`
and does not use `len()` or any imports.

## Requirements

- Python 3.8, Ubuntu 20.04 LTS
- PEP8 compliant (pycodestyle)
- All files are executable and end with a newline
